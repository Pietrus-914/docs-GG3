---
title: "Dictionary"
description: "Key terms used across the GG3 platform"
---

| Name | Definition |
| --- | --- |
| Chests | Chests that can be earned by completing Quests on the GG3 platform, containing various rewards with different probabilities. A Chest is rewarded for completing a MainQuest. |
| User | A person registered on the GG3 platform. |
| Rewards | Rewards that can be earned for completing various types of Quests on the GG3 platform. |
| Achievements | Graphics-based rewards awarded for recurring activity on the platform — e.g. reaching level 10, 50, etc., clicking the GG-Button a certain number of times (7, 30, etc.), completing X Quests (25, 50, 100, etc.). Non-exchangeable, non-tradable, non-withdrawable. |
| Badge | Graphics-based rewards for completing a specific MainQuest, not awarded for recurring activities. May relate to an event, e.g. participating in pre-registration. Non-exchangeable, non-tradable, non-withdrawable. |
| Quest | General term for tasks — Quest is synonymous with MainQuest and refers to the entire set of tasks needed to obtain a reward Chest. |
| MainQuest | The main task on the GG3 platform, consisting of SubQuests. The reward for completing a MainQuest is always a Chest, along with optional additional rewards (Badges, Achievements). |
| SubQuest | A part of the MainQuest, a single task, such as liking an account on X or owning a game on Steam. The reward for completing a SubQuest is always a set amount of XP. |
| Educational SubQuest | May contain slides, graphics, or videos. Its purpose is to educate users and may end with a quiz. |
| Integrative SubQuest | Involves the user connecting an integration like X, Discord, Google, or a Web3 wallet. |
| Verification SubQuest | Involves verifying whether the user has performed a specific action, such as liking a post or completing an internal SubQuest. Verification tasks are checked via the partner's API. |
| Affiliate SubQuest | Related to completing tasks from affiliate campaigns. |
| Internal SubQuest | Related to the GG3 platform, where task completion verification involves checking our database. Examples of internal tasks include reaching a level, clicking the GG-Button, account age, etc. |
| XP | Experience Points collected on the platform used to gain levels and influence leaderboard rankings. |
| G-Bucks | The virtual currency of the GG3 platform, with a fixed value in USD: **100 G-Bucks = 1 USD**. It is not a cryptocurrency. |
| GG-Button | A shiny button in the upper-right corner of the website that may be clicked once per day. Through dedicated Quests, consecutive days without missed clicks are rewarded with XP, G-Bucks and Achievements. The button is reset once a day, at a fixed time. |
| Leaderboard | Ranking of gamers (GG3 users) sorted by most XP earned. |
| Steam Cards | A type of reward in the form of a Steam card allowing purchases on the Steam platform. |
| Gift cards (Roblox, Riot) | A type of reward in the form of gift cards (codes) allowing to top up in-game wallets accordingly. |
| Discount codes | Discount codes that can be earned as a reward from MainQuests (from Chests). Discounts may vary and can be used on the partner's site. |
| Community | Presentation of a specific project — on the GG3 platform, partners or projects wanting to feature their Quests can set up a project page with basic information such as name, description, and assigned MainQuests. |
| Community Leaders | Each Community presented on GG3 has its own Leaderboard, a ranking of users most engaged with the Community. The more Quests from a given Community completed, the more XP earned and the higher position in the Community Leaderboard. |
| Avatar / Logo | "Avatar" refers to the user's virtual image displayed in their public profile or on the leaderboard. For communities and MainQuests, "avatar" refers to the project/MainQuest logo. |
| Cover photo | A graphic filling the background on community pages and on the cards and pages of MainQuests/communities. |
| Home | The main page for GG3 users, containing sections with Quests and projects. URL: [gg3.org/home](https://gg3.org/home) |
| User Dashboard | A page containing information for logged-in users, with tabs for account Summary, orders, discounts, referrals, and settings. |
